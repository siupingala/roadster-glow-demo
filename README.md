# Roadster Glow Demo

手機友善 Web demo：簡化 Roadster＋頭尾燈／轉燈／煞車燈／thruster glow／起飛；轉彎慢斜、減訓。

**新增：** 後／前鏡頭實景背景（`getUserMedia`）。手機用 HTTPS 開，按「開啟後鏡頭」允許權限。

> 概念 demo，非 Tesla 官方產品。商標與外形請勿用於商用。

## 試用

- 即時試用：[raw.githack demo](https://raw.githack.com/siupingala/roadster-glow-demo/main/index.html)
- GitHub Pages：https://siupingala.github.io/roadster-glow-demo/
- Repo：https://github.com/siupingala/roadster-glow-demo

## 操作

- 開鏡頭／前後鏡切換（底部掣）
- 拖曳／`A` `D`：轉彎（慢斜）
- `W` `S`：加減
- 頭燈、煞車燈、轉燈、Thruster、起飛

## 注意

- iPhone／Android 要用 **Safari／Chrome 經 HTTPS**；`file://` 通常開唔到相機
- 桌面多數只有一個鏡頭；前鏡會左右鏡像
